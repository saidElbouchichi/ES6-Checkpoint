# ES6 Checkpoint — GOMYCODE

Checkpoint du module **ES6** du bootcamp *Développement logiciel avec compétences en IA* (GOMYCODE).

**Objectif :** obtenir 300 points d'honneur sur CodeWars en résolvant des katas en JavaScript.

| Langage | JavaScript (ES6+) |

## Notions ES6 utilisées

- Fonctions fléchées (`=>`)
- Template literals (`` `${...}` ``)
- Déstructuration (`const [a, b, c] = names`)
- Opérateur spread / rest (`[...str]`, `(...values)`)
- Méthodes de tableaux : `map`, `filter`, `reduce`, `includes`, `sort`
- Méthodes de chaînes : `endsWith`, `padStart`
- `Set`, `const` / `let`
